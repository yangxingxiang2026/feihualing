## 二、验收结论（独立复验，非成员自报）

- 单测 **50/50**（judge 20 + candidates 7 + match 11 + corpus 9 + scenes 3 + walkthrough-fix 9）
- CI 门禁 **15/15**（id/norm_key 唯一、三索引一致、8 字池 24/24 覆盖 ≥12、体积 ≤260KB、source 100%、字块干扰不变量 24 组全排列 0 违例）
- 无头冒烟：两模式全相位 + 触摸路径零异常；热区 home 4 / blocks 12 / choice 5 / result 2，三屏幕帧全部 ≥88px
- UI 还原度走查两轮：首轮 7 FAIL（含字块接错崩溃、结算无跳转两条 critical）→ 修复 → 第二轮全 PASS

## 三、如何在微信开发者工具运行（3 步）

1. 打开微信开发者工具 → 导入项目 → 目录选 `D:/work/code/飞花令/minigame` → AppID 选「测试号」
2. 编译即进首页，两种模式均可完整对局（点选接句：点卡片提交；字块拼句：点字组句、撤销/清空/提交）
3. 真机预览扫「预览」二维码；本地回归：逐文件 `node tests/*.test.js` + `node tools/build/ci-gate.js`

## 四、真机待验清单（本环境无法覆盖）

1. 帧率：L1 小虎 ~180 path，预算 ≤3ms；超了按四步降级（砍底纹→冻结呼吸→浮字静态→描边降细）
2. `ctx.ellipse` 兜底分支、胶囊菜单实测值、低端机帧率
3. 亮暗两主题结算页截图目测（断言未覆盖 strokeStyle 与位置）；F7 进度环与两位数倒计时 ~7px 潜在擦边目测
4. 120px 关键字 fillText 字形与字体授权风险（v0.2 换矢量路径）；CJK 扩展 A 生僻字（㧐）真机渲染
5. 裸 667 缺省帧全屏底锚为 567（非 552），真机传真实 safeArea 后无跨屏不齐——记录备注

## 五、已裁决口径（v0.1 锁定，v0.2 不翻案除非书面重开）

- 句口径=单句；judge 纯 JS；8 字池（人山风月春花天水），「笛」出池；点选候选数锁 4（可配置）；长句=省略号+点击回显，32px 地板不豁免；错因文案 v2 映射（含「」口径）；按下态 tint-only（v0.2 若补缩放只能子区域 blit，禁 L0 全量重绘）；底锚 fallback 统一 `||0`；设置面板 v0.1 仅字号三档循环，主题/减弱动效开关 v0.2。
